user_id Column Specification

This column is designed to uniquely identify each user record in the users table.

AttributeDescription
Column nameuser_id – unique identifier for the user.
TypeBIGINT – stores large whole numbers.
UnsignedUNSIGNED – allows zero and positive numbers only.
Auto IncrementAUTO_INCREMENT – MySQL automatically generates the next ID.
KeyPRIMARY KEY – uniquely identifies each user record.

Use this column as the primary reference for user‑related operations.

Email Column Specification

This column stores user email addresses and must be unique across all accounts.

AttributeDescription
Column nameemail – user's email address.
ConstraintUNIQUE – prevents two accounts from having the same email.

Timestamp Column Specification

This column stores the date and time a record was created or updated.

AttributeDescription
Column namecreated_at – timestamp of when the row was created.
TypeTIMESTAMP – stores date and time.
ConstraintNOT NULL – a timestamp must exist.
DefaultDEFAULT CURRENT_TIMESTAMP – automatically saves the current database time when the row is created.
